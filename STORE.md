# Публикация в Chrome Web Store

Состояние на 2026-09-15. Версия пакета — `1.0.2`, собирается в `dist/dbb-1.0.2.zip`
командой `pwsh -File build.ps1` (41,9 КБ, 20 файлов).

| | |
|---|---|
| Manifest V3 | да |
| Иконки 16 / 32 / 48 / 128 | да, PNG |
| `default_locale` + `_locales/en`, `_locales/ru` | да, 76 ключей, обе локали полные |

Про мультиязычность: интерфейс переключается по **языку интерфейса браузера**
(`chrome.i18n.getUILanguage()`), не по языку страницы и не по языку системы. Проверено
запуском Chrome с `--lang=en-US` — панель, контекстное меню, попап, настройки и
заголовок новой вкладки становятся английскими. Название и описание в самом магазине
тоже локализуются автоматически, потому что они заданы через `__MSG_*__`.

## Чего не хватает

### 1. Аккаунт разработчика

- Регистрация в Chrome Web Store Developer Dashboard, **единоразовый взнос $5**.
- На аккаунте Google обязательна двухфакторная аутентификация.
- Подтверждённый контактный e-mail издателя. У новых аккаунтов первая публикация
  проверяется дольше.

### 2. Политика конфиденциальности — **обязательна**

Расширение работает с закладками и запрашивает доступ ко всем сайтам, поэтому в
магазине потребуют ссылку на политику конфиденциальности. Её нужно где-то разместить
(GitHub Pages, gist, свой сайт) и указать URL в разделе Privacy.

Черновик, соответствующий тому, что расширение реально делает:

> Расширение «Панель закладок в две строки» не собирает, не хранит и не передаёт
> никакие персональные данные. Оно читает и изменяет закладки браузера только по
> команде пользователя и только локально, через API `chrome.bookmarks`. Настройки
> хранятся в `chrome.storage.sync` и синхронизируются исключительно средствами вашего
> аккаунта Google. Расширение не выполняет сетевых запросов, не содержит аналитики,
> рекламы и стороннего кода, не читает содержимое посещаемых страниц и не передаёт
> данные третьим лицам.

### 3. Материалы карточки

| Материал | Требование | Состояние |
|---|---|---|
| Скриншоты | минимум 1, до 5, **1280×800** или 640×400, PNG/JPEG без альфа-канала | **нужно сделать** |
| Значок в магазине | 128×128 | берётся из пакета, готов |
| Small promo tile | **440×280** | **нужно сделать**, без него карточка не попадёт в подборки |
| Marquee promo tile | 1400×560 | по желанию |
| Подробное описание | текст | черновик ниже |
| Категория | выбрать | рекомендую «Productivity / Инструменты» |

**Важно про скриншоты.** Снимать их нужно на отдельном демонстрационном наборе
закладок. Тестовые снимки, сделанные на вашем реальном профиле, содержат личные
ссылки, имя в LinkedIn и рабочие вакансии — публиковать такое нельзя. Заведите чистый
профиль, положите десяток нейтральных закладок, и снимайте.

### 4. Обоснования разрешений

Их придётся вписать в дашборде отдельно для каждого пункта. Готовые формулировки:

- **`bookmarks`** — расширение целиком состоит из панели закладок: читает дерево
  закладок, чтобы её нарисовать, и изменяет его, когда пользователь переименовывает,
  удаляет, добавляет или перетаскивает закладку.
- **`storage`** — хранит настройки панели (число строк, тема, размеры, список
  сайтов-исключений) и буфер операции «вырезать/копировать» для закладок.
- **`favicon`** — показывает значки сайтов рядом с закладками, как это делает
  встроенная панель. Значки берутся из локального кеша браузера, сеть не используется.
- **`<all_urls>`** (host permission) — панель закладок должна быть видна на любой
  открытой странице, ровно как встроенная. Расширение не читает и не изменяет
  содержимое страниц: оно добавляет собственный элемент в закрытом shadow root и
  смещает страницу вниз на высоту панели.
- **Подмена новой вкладки** — на служебной странице `chrome://newtab/` расширения
  выполняться не могут, поэтому единственный способ показать панель закладок и там —
  заменить страницу собственной. Страница пустая: только панель закладок, без поиска,
  рекламы и подмены поисковой системы.

### 5. Единственное назначение (Single Purpose)

Формулировка для поля «Single purpose»:

> Показывать панель закладок браузера в несколько строк вместо одной, сохраняя вид и
> поведение встроенной панели.

Риск, о котором стоит знать заранее: **подмена страницы новой вкладки** и **доступ ко
всем сайтам** — два пункта, из-за которых проверка почти наверняка будет дольше
обычного, а иногда приходит запрос на уточнение. Оба обоснованы задачей расширения, но
описать их в карточке нужно явно, иначе это выглядит как скрытая функция. Если хочется
пройти проверку быстрее — можно выпустить первую версию без `chrome_url_overrides`
(убрать блок из манифеста) и добавить подмену новой вкладки во второй версии.

### 6. Мелочи в манифесте

- `homepage_url` — не заполнен. Не обязателен, но полезен, если будет репозиторий или
  страница поддержки.
- `author` — не заполнен, не обязателен.
- `version` при каждой повторной публикации обязан расти.

## Черновик описания карточки

### Русский

**Название:** Панель закладок в две строки

**Краткое описание:** Точная копия панели закладок Chrome, но в две строки, с тем же
поведением.

**Подробное описание:**

> Если закладок больше, чем помещается в одну строку, половина из них прячется за
> кнопкой «». Это расширение показывает панель закладок в две строки — или в три и
> четыре, как захотите.
>
> Панель выглядит и ведёт себя как встроенная: цвета, размеры и шрифт сверены с
> оригиналом попиксельно.
>
> • Папки с выпадающими меню и вложенными подменю
> • Значки сайтов из кеша браузера
> • Контекстное меню: открыть в новой вкладке, окне или инкогнито, изменить,
>   переименовать, вырезать, копировать, вставить, удалить, добавить страницу или папку
> • Перетаскивание закладок внутри панели и внутри меню, в том числе внутрь папок
> • Отмена удаления — папка восстанавливается целиком
> • Прокрутка панели колесом мыши: скрытые ряды подтягиваются по одному
> • Светлая и тёмная темы, размеры и подписи настраиваются
> • Список сайтов, где панель не показывается
>
> Чтобы не было двух панелей сразу, скройте встроенную сочетанием Ctrl+Shift+B.
>
> Ограничения, о которых честно стоит сказать: панель нельзя показать на служебных
> страницах Chrome (настройки, история, Интернет-магазин), а закладки-букмарклеты
> (javascript:) не работают — Manifest V3 запрещает расширениям выполнять
> произвольный код.
>
> Расширение не собирает никаких данных и не делает сетевых запросов.

## Перед каждой публикацией

```powershell
pwsh -File build.ps1          # собирает dist\dbb-<version>.zip и печатает состав
```

Проверьте, что в списке нет ничего, кроме `manifest.json`, `_locales`, `background`,
`content`, `icons`, `newtab`, `options`, `popup`.
